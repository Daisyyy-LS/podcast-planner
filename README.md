# podcast-planner

> 一个把"嘉宾信息 + 对谈主题 + 具体问题"一键生成播客策划案的 WorkBuddy 技能。

## 它能做什么

`podcast-planner` 把一套成熟的播客策划工作流固化成可复用技能。你只需要告诉它**嘉宾、主题、这期的作用、形式、是否有赞助商**，它就会：

1. **交互收集需求** —— 先用提问补齐关键信息（嘉宾是谁、主题方向、商业目标、节目形式与时长、赞助商及核心理念 / 软广占比、播出档期），至少先确认嘉宾和主题再开工。
2. **调研嘉宾** —— 通过公开渠道核实职务、职业时间线、代表观点原话、品牌关键事实；查不到的信息（如年龄、团队规模、经销模式）列入"待核对清单"，**绝不编造**。
3. **设计议题** —— 围绕**一个统一主题**，把三类问题穿插编排：
   - **A 网感热点钩子**：蹭当下讨论度高的话题（例如某个社交热点如何与节目主题交叉）。
   - **B 消费者科普**：人人关心、能落地的知识（例如几十块到几百块的产品到底差在哪）。
   - **C 嘉宾个人线**：他在品牌建设中的关键决策、遇到的困境、怎么解决。
   - 软广只落 1–2 个主点 + 结尾轻合流（占用比 ≤20%）；并写死红线（不提医疗功效、不制造国货 / 进口对立等）。
4. **输出策划案** —— 按统一格式生成 Markdown（标题 + 主题一句话 + 编号话题一句话说明 + 每题下方「信息概要 + 出处」+ 软广落点 + 红线），可直接拿去录制。

## 什么时候用它

- 要做一期有嘉宾的播客 / 视频对谈，需要一份结构清晰、有话题度又不尬吹的策划案。
- 有品牌赞助，希望把核心理念"夹带"进内容而不是硬广。
- 想要"网感 + 消费者价值 + 嘉宾专业壁垒"三重匹配的话题，而不是泛泛的议题罗列。

## 安装

将本仓库克隆到 WorkBuddy 的技能目录（用户级，跨项目可用）：

```bash
git clone <this-repo-url> ~/.workbuddy/skills/podcast-planner
```

重启或刷新 WorkBuddy 后，在对话中说"帮我做个播客策划"或输入 `/podcast-planner` 即可触发。

> Windows 用户请把 `~/.workbuddy` 替换为 `%USERPROFILE%\.workbuddy`。

## 目录结构

```
podcast-planner/
├── SKILL.md                  # 四步工作流主指令
├── references/
│   ├── workflow.md           # 详细方法论（调研清单 / 三类问题设计套路 / 软广夹带写法 / 红线模板 / 每个话题的溯源与信息概要 / 选题节奏）
│   └── output_template.md    # 策划案输出模板，直接套用
└── README.md
```

## 策划案输出格式

```
# 第X期｜主持人 × 嘉宾：主题一句话
整期主题：……（一句话概括，并点出与品牌 / 赞助理念的关系）

1) 话题标题 —— 一句话说明（网感 / 科普 / 嘉宾线 标注其一）
   > 信息概要：≤400 字，归纳该话题涉及的真实事件/数据/案例（含"之前有无新闻、哪些品牌被曝光、关键数字与日期")
   > 出处：2–4 个真实可点击链接，格式「来源名，日期」+ URL
2) ……
……
N) 收尾话题 —— ……

【软广落点】仅 1–2 处主落点 + 结尾轻合流，全片占比 15%–20%
【红线】不提医疗功效 / 不做国货进口对立 / 关税等灰区只谈经营与价格 ……
```

## 备注

本技能仅包含**方法论与模板**，不打包任何具体客户的策划内容。实际生成内容由每次对话的嘉宾与主题决定，不会随技能一同分发。
