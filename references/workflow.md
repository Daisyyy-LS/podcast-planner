# 播客策划方法论（详细）

本文件是 `podcast-planner` skill 的详细方法论，供生成策划案时参考。核心是把"一个嘉宾 + 一个方向"变成"统一主题下、三类问题穿插、能传播、能录制"的议题稿。

---

## 一、嘉宾调研清单（Step 2）

公开渠道（WebSearch / WebFetch）优先核实以下维度，按"可核实 / 待补充"两栏记录：

- **现任职务**：公司、职位、任职起止年份。
- **职业时间线**：关键跳槽节点、每段做了什么（渠道？品牌？市场？）。注意其能力底色（如"渠道与分销出身"还是"纯品牌营销出身"），这决定他能答哪类问题。
- **代表观点**：访谈 / 演讲 / 文章中的原话，保留出处与日期。原话是节目金句来源。
- **其品牌 / 公司的关键事实**：成立年份、全球/中国规模、主力品牌、近期发布会、市场数据、组织动作（如出售业务线、渠道调整）。
- **近期动作**：过去 6–12 个月的公开事件（新品首发、合作签约、行业峰会发言），最适合做"一手案例"。
- **待核对（公开查不到）**：年龄、团队规模、具体经销/直营模式、未公开业绩。列入清单，不要编造。

## 二、三类问题的设计套路

每个话题都要归属 A / B / C 之一，且整期三类混合编排。设计时可对照"三重匹配"：网感 × 消费者关心 × 最适合由他答。

### A. 网感热点钩子（开场炸场、蹭传播）
套路：
- **近期热梗**：如"大水理论"（戒饮料改灌白水）——找到它与本期的科学接口（如含糖饮料伤牙釉质）自然接入。
- **数据反差**：官方白皮书/统计中反直觉的数字（如"只有 1/3 人每天刷两次牙""刷牙只清了 25% 牙面"），自带传播与对号入座。
- **站队引战**：争议性话题（如"冲牙器是智商税还是真香""平替 vs 进口"），评论区天然会吵。
- **社死/日常痛点**：高共鸣场景（口气社死、合租刷牙声音羞耻），人人能接。

### B. 消费者科普（有用、能带走）
套路：
- **参数 / 价格带对比**："几十块和几百块的 XX 差在哪""99 到 3999"，教普通人看参数不交学费。
- **避坑指南**：行业乱象、营销话术拆解、"从业者自己不买什么"。
- **破除误区**：用医学/行业共识破常见误解（如"口臭九成是牙的锅不是胃""冲牙器不能替代牙线"）。
- 科普必须基于可核实来源，不夸大、不越界到医疗建议。

### C. 嘉宾个人线（只有他答得了）
套路：
- **关键决策**：在品牌建设/操盘中的一次重要选择，为什么这么做（一手动机）。
- **困境与解法**：任上最难的一次、踩过最深的坑，怎么解决的（故事性强、显专业）。
- **职业转折**：入行契机、从 X 到 Y 的切换（如"从 IT 运维到鱼油操盘手：一场脑梗改变的职业"）。
- **价值观金句**：其公开主张（如"经得起长期验证""做品牌先回到客户"），落到具体产品上怎么体现。

## 三、软广夹带写法（有赞助时）

- 仅选 **1–2 个主话题**自然落地核心理念（如"正品机制""进口新品供给"），加【软广落点：XXX】标注。
- **结尾一句话轻合流**：用不超过 30 秒的一句收口（如"进博会同期，天猫国际海外新品同步上架"）。
- 全片占比 = 用户给定上限（默认 ≤20%）。
- 禁忌：不念稿；不在避坑/批判/智商税环节硬插品牌；不让嘉宾变成"带货主播"人设。

## 四、红线模板（写入策划案末尾）

通用四条，按节目主题增删：
1. 保健品 / 个护 / 食品类：**不宣称治疗、医疗、疗效**（只讲日常护理、生活习惯、科普）。
2. 国货 vs 进口 / 平替：引导成"各有护城河"，不做阵营对立。
3. 行业翻车案例：作为"行业乱象"谈，不做人身攻击、不点名抹黑其他品牌。
4. 关税 / 宏观敏感：只谈对经营与终端价影响，不升地缘；如需公开聊，录制前确认嘉宾意愿。

## 五、每个话题的溯源与信息概要（信息概要 + 出处）

**这是策划案的核心交付物之一，必须落到每个话题下方。** 作用是：主持人/编导在录制前能快速核对"这个话题有没有真实事件支撑、之前有没有新闻、哪些品牌被曝光过、关键数字从哪来"，避免张口就来、也方便写切片文案时直接引用。

### 1. 哪些话题需要带出处

- **A 类（网感热点钩子）**：涉及新闻事件/社会热梗/行业翻车案例的，必须给出处（如"健雅德翻车""大水理论""优思益被央视曝光"）。溯源要回答：之前有没有类似新闻？哪些品牌被点名？事件时间与关键事实。
- **B 类（消费者科普）**：涉及统计数据/白皮书/医学共识的，必须给数据来源（如"艾瑞《2026 中国口腔护理白皮书》""科普中国：口臭 80–90% 源于口腔"）。
- **C 类（嘉宾个人线）**：涉及嘉宾原话/职业故事的，给原访谈/演讲出处（如"新华财经专访""小红书 @以备君 视频"）。

### 2. 信息概要怎么写（≤400 字）

- 归纳该话题**涉及的真实事件/数据/案例**，而不是写选题理由。
- 必须交代：**之前有没有新闻、哪些品牌/事件被曝光、关键数字与日期、谁披露的**。
- 例（"我亲自去欧洲溯源的含金量"）：写清"2026-04 优思益事件引发信任危机后，张晓忠在小红书征集用户去比利时溯源，律师带镜头走比利时总部→德国 KD Pharma→荷兰包装厂，验证'四个真实'；此前已有优思益（央视 2026-04 曝光）、诺斐丽（宁波公安 2026-07 破获，成本 40 卖 320、代工贴澳洲标）等假洋牌被查案例"。

### 3. 出处链接怎么给

- 每条话题给 **2–4 个真实可点击链接**，格式「来源名，日期」+ URL。
- 优先权威/一手：**央媒（新华社/央广网/央视）、澎湃/新浪等深度媒体、官方发布会通稿、品牌官网、行业白皮书发布页、嘉宾原访谈页**。
- **绝不编造链接**。若某话题确实查不到公开来源，写"（暂无公开报道，建议录制前由嘉宾团队提供）"，不要硬凑。

### 4. 检索方法

- 用 `WebSearch` 以「事件关键词 + 媒体名/年份」定向找（如"健雅德 无备案 澎湃 2026"）。
- 用 `WebFetch` 抓取报道原文，提取关键事实与日期，再回填到「信息概要」，**保留原文数字，不要换算或改写**。
- 同一事件若有多个报道，取权威口径，并在出处并列 2 条以上供核对。

## 六、选题节奏（推荐顺序）

1. **开场钩子（1–3 题）**：选网感最强或数据反差最大的，用于破冰与炸场。
2. **消费者科普（3–5 题）**：把主题讲透、让观众有获得感。
3. **嘉宾个人线（3–5 题）**：决策、困境、转折、金句，建立人物。
4. **收尾（1 题）**：落回长期主义/温暖收尾，或轻合流软广。
整体 10–14 题较适合 30–45 分钟成片（拍摄约 90 分钟）。

## 七、待核对清单模板（文末附）

> 录制前待核对（公开渠道查不到）：嘉宾年龄、中国区团队规模、具体经销/直营模式、未公开业绩数据——建议从嘉宾团队确认，避免现场说错。
